# 音声アノテーションの仕事 — リサーチレポート

> 調査日: 2026-07-19 ・ 方法: 並列 WebSearch による検索ベース調査
> **方法の正直な開示:** 当初 deep-research ハーネス（検索→本文取得→敵対的検証）を実行したが、国内アノテーション関連サイトの大半が bot 対策で本文取得を拒否（HTTP 403）したため、検索結果スニペットベースの調査に切り替えた。よって本レポートは v1 提案書のような「主張ごとの敵対的検証」を経ておらず、**単価等の数字は複数ソースの概ねの一致を確認したレンジ**として読むこと。

---

## 結論（先に正直に）

1. **単純な文字起こし系は時給換算 500〜1,000円**（初心者）で、積極的にはすすめられない。自動音声認識（Whisper 等）の進歩で単価下落圧力も強い。
2. **桁が変わるのは「AI 評価・RLHF 系」のグローバルプラットフォーム**——時給 $30〜70（約4,000〜4,500円平均）の報告が複数。ただし**案件の消滅リスクが実証済み**（後述の Scale AI/Meta 事件）。
3. 市場全体は急成長中（2025年 $19.1億 → 2026年 $25.1億 → 2030年 $73.2億予測）だが、成長の中身は「単純ラベリング」から「RLHF・品質評価・AI支援アノテーションの QA」へシフトしている。**参入するなら評価・QA 側**。
4. 「月収50万円マニュアル」等の**有料情報商材が多い領域**なので、note の有料記事等には警戒。

## 1. 仕事の種類と作業内容

| 系統 | 内容 | 求められる力 |
|---|---|---|
| **文字起こし系** | 音声→テキスト変換。音声認識AIの教師データ。ケバ取り・整文のルール順守 | タイピング速度・表記ルールの正確さ |
| **ラベリング系** | 話者識別（誰が話しているか）、感情ラベル（喜怒哀楽）、発話意図、音素・イントネーション付与 | ガイドライン読解・一貫性 |
| **区間切り出し系** | 発話区間検出（発話/非発話の識別）、ノイズ区間のタグ付け | 集中力・ツール操作 |
| **収録系** | 指定フレーズの読み上げ録音、自由発話収録（音声認識・合成の学習用） | 静かな環境・マイク（3〜5万円の機材から） |
| **評価・QA系** | AI出力（音声認識結果・合成音声・LLM応答）の品質評価、他アノテーターの成果物チェック、RLHF | 判断の一貫性・（多くは）英語での指示理解 |

用途: 音声アシスタント、会議文字起こし、コールセンター分析、音声合成など。

## 2. 単価相場の実態

| 仕事 | 単価 | 時給換算 |
|---|---|---|
| 文字起こし（国内クラウドソーシング） | 音声1分あたり 50〜100円が中心（案件により200円前後の情報も） | **500〜1,000円**（音声10分の処理に約1時間が目安） |
| 文字起こし（プロレベル） | 音声1分 200〜300円 | 2,000〜3,000円 |
| Appen（長期プロジェクト） | 時給約 $19 | **約2,000円**。ただし単発案件は極小単価もあり、月収は数万〜最高20万円弱と波が大きい |
| Outlier 等（RLHF・AI評価系） | 時給 $30〜70 の報告 | **平均 4,000〜4,500円**の報告。週払い。※後述のリスク必読 |
| 雇用型（国内求人） | 時給 最大1,800円程度／正社員 年収370〜600万円 | 未経験歓迎あり。QA 経験が問われる場合も |
| 宅録ナレーター（参考・隣接領域） | — | 月5万円が現実的ライン。機材投資は3〜5万円から |

## 3. 主なプラットフォーム・会社

- **国内クラウドソーシング:** クラウドワークス、ランサーズ（文字起こし・かんたん作業系。単価は低い）
- **グローバル:** Appen／CrowdGen（音声収録・文字起こし・識別。指示は英語）、Outlier（Scale AI 系・RLHF）、DataAnnotation、Mercor 等の後発
- **国内アノテーション会社（受託・求人）:** FastLabel、ヒューマンサイエンス、Datatang、pluszero、東京反訳 など。Indeed／求人ボックスで「アノテーション 在宅」検索
- **求人動向:** 在宅可の募集が多数。画像系含むアノテーション求人は Indeed で600件規模

## 4. AI の進歩が需要に与える影響（2025〜2026）

**市場は拡大中:** 2025年 $19.1億 → 2026年 $25.1億 → 2030年 $73.2億の予測（別レポートでは CAGR 約26.8%）。2026年のトレンドは **RLHF アノテーション**と **AI 支援アノテーション**の2本柱。

| 消える・縮む領域 | 増える領域 |
|---|---|
| 単純文字起こし（自動音声認識の精度向上・自動/半自動ツール・合成データで手作業が削減） | LLM/音声AIの **RLHF・品質評価**（時給が最も高い） |
| 単価の低い大量ラベリング | **感情・意図など人間の判断が要るラベル** |
| — | **多言語・日本語ネイティブ枠**（グローバル勢の日本語データ需要） |
| — | AI がつけたラベルの**検収・QA**（AI支援化するほど QA 需要は増える） |

**実証されたリスク:** 2025年6月、Scale AI への Meta 大型出資により、競合（Google・OpenAI 等）が発注を引き揚げ、**Outlier の案件が6月に激減→7月にほぼゼロ**になったという複数の報告。プラットフォーム一本足は危険で、案件消滅は「起こりうる」ではなく「起きた」。

## 5. 始め方（在宅・副業）

1. **機材:** PC＋静かな環境。収録系はマイク（まず3〜5万円以内。案件が安定してから強化）
2. **国内で小さく試す:** クラウドワークス等で文字起こし1〜2件——ただし時給500〜1,000円の世界だと体感した上で、長居しない
3. **英語がいけるなら直接グローバルへ:** Appen／DataAnnotation／Mercor 等に登録（指示文は英語。テスト合格→案件待ちで、返事が来ない・不合格は「当たり前」の世界）
4. **複数プラットフォーム併用**でプラットフォーム消滅リスクを分散
5. **評価・QA 系のトラックレコード**を作り、単純作業から早く卒業する

## 6. キャリアとしての将来性

- アノテーター → **チェッカー/QA リード → プロジェクト管理**の道は実在（Appen で1年後にマネージャー打診を受けた体験談あり）
- 雇用型なら正社員 年収370〜600万のレンジ。品質管理・ガイドライン設計ができる人材は自動化が進むほど希少に
- ただし「作業者」のままでは自動化と単価下落の圧力を正面から受ける。**単価が守られるのは判断・品質・管理の層**

## 7. 注意点

- 有料 note・情報商材（「月収50万円完全マニュアル」等）が多い領域。登録自体は無料でできるので、**商材を買う必要はない**
- 海外プラットフォームは報酬受取（Payoneer 等）・税務（雑所得/事業所得）の手間がある
- 案件は「ある時は集中、ない時はゼロ」。生活の主軸にするのは危険で、副収入と割り切るのが現実的
